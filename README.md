## 能做什么
- **战壕**：新创建 / 即将打满 / 已开盘 三列，覆盖 Flap、Four、gang.fun（Gang V1 / V2 / V3、打新）。每张卡片固定格式：名字 → 底池配对币 · 税率 · 发射模式 → 池子 / 标签 → 时长 · 持有人 · 笔数 → Dev / 首买。
- **筛选**：每列 P1 / P2 / P3 三套预设，按平台、报价代币、创建时间、市值、持有人、进度、税率、社交链接过滤，自动保存。
- **K 线与成交**：已开盘代币合并链上成交与外盘历史，市值 / 价格切换，1s 到 1h 多周期，买卖点标注。
- **行情页**：左栏「内盘中 / 即将发射 / 已迁移 / 我的」和战壕三列同一套筛选；代币详情头部一行看全价格、涨幅、市值、底池、成交量、持有人、费率和各平台链接。
- **一键买卖**：快速买入、清仓、滑点、授权查看与撤销；买卖走币安聚合，聚合没收录的新池子直连 PancakeSwap V2。
- **追踪 / 跟单**：盯住聪明钱地址，按你设的金额自动跟买、止盈止损。
- **gang.fun 狙击**：新盘一出就买，每次买多少、每天最多狙几个（默认不限）、自动卖出，都由你定。
- **NFT 雷达 + 自动 mint（0.3.7 新增）**：新项目由作者统一监听并推送（你不用配置任何东西），列表里标出「免费 + 有 Agent ID」的；打开自动 mint 后，服务端自动 mint 免费项目（只花 gas、付费的永远手动）。可按官网 / X 条件筛选、设排除关键词，页面里看成功 / 失败报告和累计 mint 数据，历史可按任务时段查询。详见下面「NFT 雷达与自动 mint」。
- **最新 NFT 浮窗**：全站任何页面（包括战壕）都能点「最新 NFT」打开浮窗，可停靠到左 / 右侧。
- **任务灯**：顶部「狙击 / 跟单 / NFT」三个任务，开着是绿灯、关着是灰灯，不用点进去就知道在不在跑。
- **统一界面**：全站子导航统一成下划线页签，字号、卡片、间距统一；窗口缩小时整体等比缩放，布局不会乱。
- **免费 mint 脚本**：`node scripts/free-mint.mjs 0x合约…`，自动试出免费数量、用 baw 预览做安全检查后才 mint；付费的只报价不执行，`--dry` 只检查不发交易。
- **全部暂停**：右上角一个按钮，同时停掉追踪和狙击。
- **自检页**：一眼看到钱包、实盘开关、各模块是否正常，哪里不对会用大白话告诉你。
- **单钱包**：只用你登录的那一个币安 Agentic Wallet，界面里不会出现多钱包的选项。

## 3 分钟上手
**环境**：Mac、Windows 或 Linux，Node.js 22 或更新（去 <https://nodejs.org> 下载安装，Windows 装完要重新打开窗口）。

### Mac / Linux
```bash
git clone https://github.com/H-eartbreaker/bsc-agent.git
cd bsc-agent
./install.sh      # 检查 Node、装依赖、生成 .env、安装币安钱包命令行 baw
./start.sh        # 启动并自动打开 http://localhost:8787
```
没装 git？在 GitHub 页面点 **Code → Download ZIP**，解压后在这个文件夹里打开终端运行同样的两条命令。

### Windows
1. 在 GitHub 页面点 **Code → Download ZIP**，解压到任意文件夹（装了 git 也可以 `git clone`）。
2. **双击 `install.bat`**：检查 Node、装依赖、生成 `.env`、安装币安钱包命令行 `baw`。
3. **双击 `start.bat`**：启动并自动打开 <http://localhost:8787>，关掉黑色窗口就是退出。
4. 第一次 Windows 防火墙或杀毒软件弹窗，选「允许」；如果 `baw` 自动安装失败，用「管理员」打开命令提示符运行 `npm i -g @binance/agentic-wallet`。

首次打开会弹出**新手引导 + 自检**，按顺序做：
1. **登录币安钱包**：打开页面后，中间会自动弹出登录窗口，点「**登录币安钱包**」→ 打开它给的链接 → 核对配对码 → 在**币安 App** 里确认，页面会自动检测，不用敲命令。（没装币安钱包工具时，窗口里会直接给出安装命令，点「复制」粘贴到终端即可。）
2. 打开页面底栏左下角「🩺 自检」，前 4 项都是 ✓ 才算准备好。
3. 在「追踪 / gang.fun 狙击」里设好**每次买多少**，先用很小的金额试一笔。
4. 想停：右上角「全部暂停」。

> 国内网络访问行情站不稳时：打开你的代理软件即可，程序会自动找代理；找不到就在「自检」页里填一下代理地址（见常见问题）。

## 安全须知（请先看）
这是第三方软件，会动真实资金，**没有做过正式安全审计**。请先小额验证。
- 真实下单需要：`MODE=live`、`LIVE_TRADE=1`、钱包已登录，并在页面里确认。
- 追踪 / 狙击默认**关闭**，重启后也**不会自动开启**。
- 服务只监听 `127.0.0.1`，不要把端口映射到公网。
- RPC key、转出地址等私密设置只放本机 `.env`，不要提交到 Git。`data/` 目录（持仓、记录、令牌）已被 `.gitignore` 忽略。
- 自动转出、自动领取、大额预授权默认关闭。

## 更新：GitHub 新版本提醒
- 程序会定时检查本仓库的版本号；有更高版本时，**右上角 GitHub 图标亮红点并弹出提示**（含更新内容）。
- 弹窗里可以选「稍后提醒」「本版不再提醒」或「去 GitHub 看看」。
- **只提醒，不会自动更新。** 更新方法：
  ```bash
  git pull
  npm install
  # 然后重启服务（停掉再 ./start.sh）
  ```
  你的钱包、设置、记录（`data/`、`.env`）不会被改动。
- 想检查别的仓库：`.env` 里设 `BSC_AGENT_UPDATE_REPO=用户名/仓库名`；想关闭：`BSC_AGENT_UPDATE=0`。
- 每次的更新内容见 [CHANGELOG.md](CHANGELOG.md)（[English](CHANGELOG.en.md)）。

## 配置
复制 `.env.example` 为 `.env` 后按需修改（`install.sh` 已替你做了）：

| 变量 | 默认 | 说明 |
|---|---:|---|
| `MODE` | `live` | 实盘模式（默认） |
| `PORT` | `8787` | 本地端口 |
| `LIVE_TRADE` | `1` | `1` 登录后可真实下单；`0` 只看行情、只报价 |
| `MAX_TRADE_BNB` | `0.5` | 单笔买入上限（BNB），安全阀 |
| `NODEREAL_RPC` / `NODEREAL_KEYS` | 空 | 私有 BSC 节点，只放 `.env` |
| `BSC_AGENT_PROXY` | 空 | 访问行情站的代理，例如 `http://127.0.0.1:7897` |
| `BAW_BIN` | `baw` | 币安钱包命令行路径 |
| `AUTO_TRANSFER_TO` | 空 | 自动转出地址（也可以在页面「自动转出」里设置，改地址要二次确认） |
| `BSC_AGENT_PROXY` | 自动 | 手动指定代理（一般不用填；填 `none` 表示不用代理） |
| `BSC_AGENT_UPDATE_REPO` | 官方仓库 | 新版本提醒检查的仓库 |
| `BSC_AGENT_UPDATE` | 开 | 设 `0` 关闭新版本提醒 |
| `MYSQL_URL` / `REDIS_URL` | 空 | 可选历史数据缓存，`scripts/enable-cache.sh` 可一键用 Docker 起 |

## NFT 雷达与自动 mint
**开箱即用，不需要任何配置。** 页面「NFT」里的新项目由作者统一监听并推送，你的程序每分钟自动拉取一次；打开「自动 mint 管理」设好规则就能用。

- 只 mint **免费**的（`value=0`）且有 Agent ID 的项目；付费的永远只提示、不自动执行。
- 每个项目先链上模拟、再过 `baw contract-call preview` 安全检查，通过才发交易，花费只有 gas。
- 可按官网 / X 条件筛选、设排除关键词；页面里看成功 / 失败报告、累计 mint 数据和历史（可按任务时段查）。
- 建议第一次先选「试运行」（不发交易），看一轮报告再切到真实 mint。
- 自动任务**重启后不会自动恢复**，需要你手动再打开。
- 推送由作者的电脑提供：作者没开监听时没有新项目，页面会提示「推送已停止」，已有项目和你的设置都不受影响。
- 不想用：`.env` 里设 `NFT_FEED_SYNC=0`。

## 常见问题
- **代币没有头像、池子显示「—」？** 头像、池子、K 线都来自国外行情站。程序会自动找代理（先直连，再读系统代理、试常见端口）。如果还是没有：打开你的代理软件，点底栏「🩺 自检」→「能连上行情站」那一项下面有个输入框，填上代理软件里的 HTTP 代理地址（形如 `http://127.0.0.1:端口`，在 Clash / V2Ray 等软件的设置里找「HTTP 代理端口」或「混合端口」），点「保存并测试」，立刻生效，不用重启。
- **右上角显示「演示账号」、页面是演示状态？** 说明用的是旧的 `.env`。更新到最新版（`git pull`）后重启即可；也可以直接删掉 `.env` 里的 `MODE=sim` 那一行，或重新 `cp .env.example .env`。

- **K 线缺一段 / 和别的软件不一样？** 历史 K 线来自 GeckoTerminal 和 DexScreener，免费接口有频率限制，页面上会出现一行黄色提示说明原因；新打开的币会在后台分页补历史，等几分钟再看。网络不通时请设置 `BSC_AGENT_PROXY`。
- **点买入提示失败？** 页面会用大白话说明原因（余额不够、滑点太低、钱包未登录等）；也可以先打开「自检」。
- **改完代码 / 更新后没变化？** 需要重启服务；浏览器按 Cmd/Ctrl+Shift+R 强制刷新。
- **怎么彻底停掉自动功能？** 右上角「全部暂停」；或直接关闭服务。
